# Three-minute demo guide

Use the full local app with a configured Meta key to record AI interpretation and generation. A Pages frontend must be connected to the same full backend. Do not show `.env`, terminal credentials, account dashboards, or keys.

| Time | Show | Explain |
| --- | --- | --- |
| 0:00–0:20 | Title and brief tour | “NapkinCloud turns architecture diagrams into reproducible traffic experiments.” |
| 0:20–0:45 | Try your architecture → Upload architecture → Demo Image | Show Simple starter, the three examples, and PNG downloads. |
| 0:45–1:10 | Upload a PNG or use a demo, review connections | Both personal and demo images go through Meta interpretation before connection review. |
| 1:10–1:30 | Launch surge sample inputs, component capacities | 3,000 peak req/s, 90% reads, 20 seconds, 99% success target. These are editable assumptions. |
| 1:30–2:10 | Run test, then Generate After | Follow the bottleneck, verified After flow, and measured simulation comparison. An insufficient result remains visible. |
| 2:10–2:40 | Findings, stress cases, image if connected | Generated illustrations explain; the simulator's graph and evidence determine results. Results are simulated, not production benchmarks. |
| 2:40–3:00 | Download experiment, History, repository and demo links | Judges can inspect source, reproduce the inputs, and try the public demo. |

Allow time for actual model calls. Edit out waiting time only with an honest cut; do not replace it with fabricated results. Generation runs only when you explicitly choose it.
